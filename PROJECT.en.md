# PROJECT.md

A documentation site for architecture patterns for integrating AI agents into production systems, **centered on decision-making (forces, degrees, tradeoffs)**. Built with **MkDocs (Material)** and published on **GitHub Pages**. The information architecture is anchored on "decisions as the backbone, patterns as the vocabulary."

- Target audience: Architects/engineers integrating AI agents into production systems **+ coding agents**
- Scale: 12 categories, 59 patterns + decision layer (core), composite configurations, anti-patterns
- Single source of truth: [`patterns.yml`](patterns.yml) + [`decisions.yml`](decisions.yml)
- Writing rules: [`CLAUDE.md`](CLAUDE.md)
- Agent integration: [`AGENTS.md`](AGENTS.md)

## Setup and Local Preview

```bash
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Batch-generate stubs for missing pattern pages & category indexes (does not overwrite existing files)
python scripts/scaffold.py

# Local preview (http://127.0.0.1:8000 / hot reload)
mkdocs serve

# Build under production conditions (fails on broken links, etc.)
mkdocs build --strict
```

## Deployment (GitHub Pages)

1. Push the repository to GitHub (default branch: `main`).
2. In `mkdocs.yml`, replace `<user>` in `site_url` / `repo_url` / `repo_name` with your own.
3. A push to `main` triggers `.github/workflows/deploy.yml`, which runs `mkdocs gh-deploy` to create/update the `gh-pages` branch.
4. In GitHub **Settings → Pages → Build and deployment → Source = "Deploy from a branch"**, set **Branch = `gh-pages` / `(root)`**.
5. After a few seconds, the site is available at `https://<user>.github.io/agent-architecture-patterns/`.

> For manual deployment, run `mkdocs gh-deploy --force`. If you prefer the GitHub Actions Pages source instead of CI, you can switch to the `upload-pages-artifact` + `deploy-pages` approach.

## Writing Workflow (Claude Code)

1. Run `python scripts/scaffold.py` to prepare stubs.
2. Open the target pattern's `.md` in Claude Code and write following the rules in [`CLAUDE.md`](CLAUDE.md).
3. Verify that `mkdocs build --strict` passes (no broken links or nav inconsistencies).
4. One pattern = one commit (e.g., `docs(#12): write Blackboard pattern`).

See [`CLAUDE.md`](CLAUDE.md) for the "Definition of Done" criteria.
