# AIエージェント本番アーキテクチャ・パターン

!!! abstract "基本原理"
    **確率的なコアを、決定論的な殻——契約・検証・予算・権限・観測——で囲む。**

## このサイトについて

AIエージェントを本番システムへ組み込むためのアーキテクチャパターン集。12カテゴリ・59パターンを体系的に整理し、それぞれの設計意図・向き不向き・要素技術・調整の勘所を解説する。

## 対象読者

AIエージェントを本番環境で運用するアーキテクト・エンジニア。プロトタイプから本番への移行で直面する「壊れ方」と、その防波堤としてのパターンを扱う。

## 構成

本サイトは4層で構成される。

1. **[土台](foundations/characteristics.md)** — AIエージェントの特性と、設計を駆動する9つの変数（フォース）
2. **[パターン](pattern-index.md)** — 59の具体的な設計パターン。12カテゴリに分類
3. **[意思決定層](decisions/tuning-dials.md)** — パターンの「程度」を決めるダイヤルと「相反」の選定基準
4. **[横断](anti-patterns.md)** — アンチパターン、リファレンスアーキテクチャ、早見表

## 読み方

- まず **[AIエージェントの特性](foundations/characteristics.md)** と **[駆動変数](foundations/forces.md)** で前提を共有する
- 課題に応じて **[パターン早見表](pattern-index.md)** から該当パターンを引く
- パターンの「程度」を決めるときは **[チューニングダイヤル](decisions/tuning-dials.md)** を参照
- 「A か B か」で迷ったら **[相反の選定基準](decisions/tradeoffs.md)** を参照
- やってはいけないことは **[アンチパターン](anti-patterns.md)** で確認
- 複合構成の例は **[リファレンスアーキテクチャ](reference-architectures.md)** を参照
