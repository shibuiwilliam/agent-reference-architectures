# 地盤（Concepts）

意思決定（程度・相反）の土台となる4つの枠組みです。新しい設計タスクでは必ずここから読み始めてください。

- [5層モデル](layer-model.md) — 全体の背骨です。特性→予算→駆動変数→程度/相反→パターンの順に構成されています。
- [設計力学 F1–F17](design-forces.md) — エージェントが普通のソフトと違う理由（＝判断が要る原因）を説明しています。
- [7つの予算](budgets.md) — 何をどれだけ配分するかを定義しています。
- [9つの駆動変数](driving-variables.md) — 程度と相反を解くための共通の選択器です。
