# 用語集（Glossary）

- **程度 (degree / dial)**: 連続的に調整する設計変数です。両側に「効きすぎる害／効かなすぎる害」があります。
- **相反 (fork / either-or)**: 排他的な二つの仕組みのどちらを採るかの判断です。
- **駆動変数 (driving variable)**: 程度・相反を決める少数の共通変数（9種）です。
- **設計力学 (force, F1–F17)**: AIエージェントが普通のソフトと異なる特性です。判断が必要になる根本原因を示しています。
- **予算 (budget)**: 時間/コスト/自律性/状態/コンテキスト/リスク/観測の7種の配分対象です。
- **意思決定層 (decision layer)**: パターン選定・程度調整・相反判定とその根拠を扱う層です。本ドキュメントの主題にあたります。
