# 1. 無限・過大タイムアウト

!!! abstract "一言"
    タイムアウトや予算上限を設定しない、あるいは過大に設定してしまい、暴走エージェントがリソースとコストを食い尽くしてしまうアンチパターン。

## よくある場面

あるチームが社内向けのドキュメント要約エージェントを開発しました。開発環境では数十秒で処理が終わるため、タイムアウトはデフォルトの30分のまま本番へ投入しました。ある日、ユーザーが数百ページのPDFをアップロードしたところ、エージェントが要約→自己修正→再要約のループにはまり込みました。処理は25分間続き、その間に数万トークンを消費。同様のリクエストが複数重なってAPIのレート制限に到達し、他のユーザーのリクエストまで巻き添えで失敗しました。

別のケースでは、コスト上限を設けていないマルチエージェント構成で、親エージェントが子エージェントを再帰的に呼び出し続けました。1リクエストあたり数万円の請求が発生し、月末の請求書で初めて気付くことになりました。

## 症状

- 1リクエストの処理時間が想定の10倍以上になることがあります
- LLM APIの月額コストが予算を大幅に超過します
- 1リクエストで数千〜数万トークンを消費し、他リクエストのレート制限を圧迫します
- エージェントの自己修正ループが収束せず、同じ処理を延々と繰り返します
- コネクションプールが枯渇し、システム全体のスループットが低下します

## 根本原因

開発環境では入力が小さく処理も正常に終わるため、問題が表に出ません。「最悪ケース」を想定したタイムアウト設計が行われず、「念のため長めに」という安全マージンがそのまま本番設定になりがちです。さらに、LLMの呼び出しコストは従量課金なのに、従来のAPIコールと同じ感覚で「タイムアウトさえ設ければ大丈夫」と考え、トークン数やコストの上限を見落としてしまうケースが多いです。

マルチエージェント構成では、親タスクの予算が子タスクに伝わらないために子タスクが独立に予算を消費し、合計コストが制御不能になることもあります。

## 発見方法

- **レイテンシ分布の確認**: P99レイテンシがP50の10倍以上ある場合は要注意です
- **コスト分布の確認**: リクエストあたりのトークン消費量のヒストグラムで、外れ値が存在するか確認します
- **タイムアウト設定の棚卸し**: 全サービスのタイムアウト値を一覧化し、「なぜその値か」を説明できるか確認します
- **メトリクス**: `request_duration_seconds` の P99、`tokens_per_request` の最大値、`cost_per_request` の最大値

## 対策

### ステップ1: 3軸の上限を設定する

時間・トークン数（またはステップ数）・コストの3つの軸で上限を設けます。どれか1つでも上限に達したら処理を中断します。

```yaml
# 設定例
timeout:
  sync_request: 10s
  async_job: 300s
budget:
  max_tokens_per_request: 50000
  max_cost_per_request_usd: 0.50
  max_steps: 20
```

### ステップ2: 子タスクに予算を伝播する

マルチエージェント構成では、親タスクの残り予算を子タスクに渡します。子タスクの予算合計が親の予算を超えないようにします。

### ステップ3: 監視とアラートを設定する

上限の80%に達した時点でアラートを発行し、実際に上限に達したケースを記録・分析します。上限値が適切かどうかを定期的に見直します。

## 具体例

### Before（問題のある状態）

```python
# タイムアウトなし、予算上限なし
response = agent.run(
    prompt=user_input,
    # timeout は未設定（デフォルト: 無制限）
    # max_tokens は未設定
)
```

### After（改善後）

```python
from agent_framework import BudgetPolicy

budget = BudgetPolicy(
    timeout_seconds=30,
    max_llm_calls=10,
    max_tokens=30000,
    max_cost_usd=0.30,
)

response = agent.run(
    prompt=user_input,
    budget=budget,
    on_budget_exceeded="return_partial",  # 途中結果を返す
)
```
