# XII. Organization, Governance & Lifecycle

    - **Primary forces**: `[F8]` Accountability, `[F2]` Failure Cost, `[F9]` Provider Reliability

When an agent takes actions contrary to organizational policies, you cannot respond or prevent recurrence if you do not know "who set which rules" or "when the prompt changed." This section covers operational design for welcoming agents as new execution entities within an organization.

- [#52 Agent Constitution](52-agent-constitution.md) — Systematically define behavioral principles and deploy across all agents
- [#53 Agent Change Management](53-agent-change-management.md) — Manage agent changes with the same rigor as CI/canary targets
