# XII. 組織・ガバナンス・ライフサイクル


!!! tip "この関心で効く意思決定"
    - **主なフォース**: `[F8]` 説明責任、`[F2]` 失敗コスト、`[F9]` プロバイダ信頼度
    - **意思決定の進め方**: [意思決定の進め方](../../decisions/decision-flow.md)

エージェントが組織の方針に反する行動を取ったとき、「誰がどのルールを設定したのか」「いつプロンプトが変わったのか」が分からなければ、対処も再発防止もできません。エージェントを組織における新しい実行主体として迎え入れるための運用設計を扱います。

- [#52 Agent Constitution｜エージェント憲法](52-agent-constitution.md) — 行動原則を体系的に定義し、全エージェントに展開する
- [#53 Agent Change Management｜エージェント変更管理](53-agent-change-management.md) — エージェントの変更を厳格なCI/カナリアの対象として管理する
