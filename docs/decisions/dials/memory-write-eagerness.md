# メモリ書き込み積極度

!!! abstract "一言"
    エージェントが長期メモリに情報を書き込む積極性を制御し、学習効率とノイズ蓄積のバランスを取ります。

## 概要

ユーザーが以前に伝えた好みをエージェントが覚えていません。しかし別のユーザーでは、一度きりの雑談まで記憶されてしまい不気味に感じる——何を覚えて何を忘れるかの判断は、エージェントの信頼感に直結します。

このダイヤルは、エージェントが対話や処理の過程で得た情報を長期メモリに書き込むかどうかの閾値を制御します。積極度が高いとあらゆる情報を記憶し、低いと明確に重要と判断された情報のみを保存します。書き込みの判断はモデルの自律判断、ルールベース、人間承認のいずれかで行います。

## なぜ調整が必要か

エージェントの長期メモリは検索ベースで利用されるため、ノイズが増えると検索精度が低下します。一方、重要な情報を書き込まないと過去の学びを活かせず、同じ失敗を繰り返します。書き込み基準がないと、メモリストアが肥大化して性能が劣化するか、空のまま活用されないかのどちらかになります。

## 値域の両端

### 小さすぎると

ユーザーの好み、過去の判断根拠、タスク固有の学びが保存されません。エージェントは毎回ゼロから判断し、対話の重複が増えます。長期的な品質向上のフィードバックループが断たれます。

### 大きすぎると

一時的な情報、ノイズ、矛盾する情報がメモリに蓄積します。検索結果に無関係な情報が混入し、ハルシネーションの種になります。ストレージコストが増加し、メモリの管理・クリーニングの負荷が高まります。

## 決め手となるフォース

- `[F8]` 説明責任・規制 — 何を記憶しているかの説明責任があり、無差別な書き込みは監査リスクになる

## 目安（出発点）

- 高信頼度の情報（ユーザーの明示的指示、確認済み事実）: 自動書き込み
- 中信頼度の情報（推論結果、暗黙の好み）: 信頼度閾値で判定
- 低信頼度の情報（1回限りの文脈、未確認の推測）: 書き込まない
- 人間承認が可能な環境: 中信頼度の書き込みを承認制にする

## 調整の実務

- 書き込まれたメモリの利用率（後続のクエリで参照された割合）を計測する
- 利用率が低いメモリカテゴリの書き込み閾値を引き上げる
- メモリの品質を定期的にサンプリングレビューし、ノイズ率を把握する
- 書き込み判断のログを保持し、判断基準の妥当性を監査可能にする
